# Macaque task timeline, version 3

- One small macaque-and-screen illustration, with the animal facing the screen.
- Native vector timeline and editable text, with a 600-dpi PNG export (8280 x 2100 pixels).
- No analysis-window shading, 500-ms label, or LFP annotation.
- Monkey T, channel 7, session y070316009-12, short-delay trials: D1 = D2 = 700 ms.
- Initial hold: 700 ms. Temporal cue: 200 ms. Spatial cue: 55 ms.
- D1 begins at temporal-cue offset; D2 begins at spatial-cue offset.
- Timing labels are nominal protocol durations, not claims that every measured event interval is identical.
- Reach latency is not assigned a number. No analysis, geometric fits, or decoding was changed.

The SVG contains native lines/text and an embedded raster illustration; it is not a fully vectorized animal drawing.
The illustration was generated with the built-in image generation tool and is embedded without editing.
The timeline was typeset programmatically to keep the text and lines sharp.

Source: [Confais et al., task methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC8152857/).
The saved recording metadata also identifies this as Monkey T and specifies the 700-ms short delay.

Regenerate with `python render_timeline.py` from this folder.
