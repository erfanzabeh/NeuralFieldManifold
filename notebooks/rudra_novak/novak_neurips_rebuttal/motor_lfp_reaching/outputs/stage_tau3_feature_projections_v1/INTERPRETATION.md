# Qualitative reading

The six stage colors overlap substantially in the 2D PCA, LDA, and UMAP views of the geometric, Betti, and combined feature sets. Some plots show continuous structure or local concentrations, but none shows six distinct held-out stage clusters. The supervised LDA views do not reverse this pattern. These are descriptive projections, not a new decoding test or a significance analysis; 2D overlap also cannot rule out information in the full feature space.
