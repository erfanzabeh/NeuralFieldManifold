# H1 counts at distance 0.25

Exploratory comparison of opposite reach directions: 1/4, 2/5, 3/6. All 198 trials are shown, with median and interquartile range. The distance was chosen after inspecting the existing curves; no significance testing or clustering claim is made. PNGs are 600 dpi.

Counts are read from saved birth/death intervals using birth <= 0.25 < death. No Ripser, fitter, or decoder is invoked. The companion curve panel marks the threshold. CSV files preserve all displayed values and horizontal jitter.
