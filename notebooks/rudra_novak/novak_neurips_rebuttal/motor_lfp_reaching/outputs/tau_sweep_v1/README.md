# Six-stage tau sweep

The four PNGs are in `figures/`: an F1 matrix and winner's recall confusion for each of the native and matched-260 sweeps. Blue outlines mark the earlier tau=3 setting; red outlines mark the highest observed macro-F1. The winner was selected from these held-out scores and is exploratory, not an independently validated optimum. Confusion diagonals are class recall, not F1. All per-tau predictions, fitted parameters, and failures are saved in the other folders.
