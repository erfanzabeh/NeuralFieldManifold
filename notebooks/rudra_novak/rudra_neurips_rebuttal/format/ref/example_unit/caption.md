# example_unit

## Caption

Example compact unit showing two deterministic synthetic measurement traces across a normalized sample coordinate. Condition A is a sine wave, and condition B is the same waveform shifted in phase and vertically offset; the unit demonstrates cache reuse, explicit recomputation, and vector PDF plot output without using external data.

## Panel Notes

- Single panel: red marks condition A and blue marks condition B across normalized samples from 0 to 1.
