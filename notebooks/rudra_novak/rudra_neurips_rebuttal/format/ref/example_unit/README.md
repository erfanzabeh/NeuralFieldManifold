# example_unit

## Method

- Generate a small deterministic example dataset inside the script so the unit has no external data dependency.
- Use `x` as 40 evenly spaced samples from 0 to 1.
- Compute two measured series: `condition_a = sin(2*pi*x)` and `condition_b = sin(2*pi*x + 0.6) + 0.2`.
- Save the computed arrays and summary values to `cache/example_unit.pkl`.
- On later runs, reuse `cache/example_unit.pkl` when it exists.
- If the script is run with `--recompute`, delete the old cached result and calculate the arrays again.
- Plot both conditions as lines and save the output to `plots/example_unit.pdf`.

## Variables

- Data/input: no external data; deterministic arrays are generated by the script.
- Sessions/groups: two example groups, `condition_a` and `condition_b`.
- Labels/targets: condition labels are used only for line identity.
- Signals/features/measures: synthetic measurement value on each normalized x sample.
- Parameters/thresholds: 40 samples from 0 to 1; phase offset is `0.6`; vertical offset for condition B is `0.2`.
- Outputs: `cache/example_unit.pkl` and `plots/example_unit.pdf`.

## Statistics

- Tests/models: none; this output is descriptive.
- Null hypothesis: none.
- Alternative hypothesis: none.
- Thresholds/decision rule: none.
- What the statistic means: no statistic is computed.
- Why this statistic is appropriate here: the example exists to demonstrate compact-unit mechanics, not to support a quantitative claim.

## Legends

- X axis: normalized sample coordinate from 0 to 1.
- Y axis: synthetic measurement value.
- Color/value: red line is condition A; blue line is condition B.
- Grouping: each line is one condition.
- Ordering/sorting: x samples are shown in ascending order.
- Lines/markers/labels: solid lines show the two conditions; the legend names each condition.
- Panels: one panel only.

## Interpretation

- This reference unit demonstrates the compact-unit pattern: one script, one cache folder, one plot folder, and a README that explains the calculation.
- The plotted values are synthetic and should not be interpreted as real project results.
